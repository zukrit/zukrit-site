# zukrit.com

Zukrits webside: forside, vilkår, privatlivspolitik og sletning af konto, på engelsk og dansk (`da/`).

- Ren HTML og `style.css`, intet byggetrin. Vises med GitHub Pages fra `main`.
- `CNAME` sætter domænet til `zukrit.com`.
- Vilkår og privatlivspolitik er **udkast** med pladsholdere i `[…]`. Fjern det gule felt (`.draft`), når teksten er gennemgået og gælder.
- Appen åbner `https://zukrit.com/terms` (se `frontend/lib/data/services/link_service.dart` i appens repo).
